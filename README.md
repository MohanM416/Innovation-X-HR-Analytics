# 📊 Innovation X – HR Analytics Dashboard | Power BI

## 📌 Project Overview

The Innovation X HR Analytics Dashboard is an interactive Power BI project designed to analyze employee data, workforce demographics, salary distribution, and employee attrition.

The dashboard provides HR teams with valuable insights into employee performance, departmental attrition, salary trends, and gender distribution across different age groups.

The main objective is to transform HR data into meaningful insights that support better workforce planning and data-driven HR decisions.

## 🎯 Project Objectives

- Analyze overall employee distribution.
- Understand employee attrition across departments.
- Compare salary distribution by job role and gender.
- Analyze employee performance ratings.
- Identify salary differences across employee groups.
- Understand gender distribution across different age groups.
- Identify employees with the highest monthly salaries.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPI development.
- **Microsoft Excel** – Data preparation and analysis.
